一、创建七牛云存储空间

  1. 登录 七牛云控制台，进入 对象存储 Kodo
  2. 点击 新建空间，配置如下：
配置项值
存储区域华南-广东（ECS 在深圳，就近选择）
访问控制公开（公有读私有写，URL 可直接访问）

创建成功后记录 空间名称，后续配置会用到。

二、配置 CDN 加速域名

进入 CDN → 域名管理 → 添加域名：

配置项值

提交后获取七牛分配的 CNAME 值（形如 cdn-yianso-cn-idvru26.qiniudns.com），下一步使用。

域名在阿里云管理，前往 阿里云控制台 → 域名 → 解析设置，添加记录：

记录类型主机记录记录值
CNAMEcdn粘贴七牛给的 CNAME 值

等待几分钟生效，在七牛点击 刷新检测，状态变为「已配置」即可。

四、服务器安装 acme.sh 并签发证书

SSH 登录到阿里云 ECS：

# 1. 安装 acme.sh
curl https://get.acme.sh | sh

# 重新加载环境变量
source ~/.bashrc

安装时会自动添加定时任务，每天检查证书状态，无需额外配置。

注册账户

# 使用真实邮箱注册
~/.acme.sh/acme.sh --register-account -m your@email.com

配置阿里云 DNS API

签发证书需要操作阿里云 DNS（添加 TXT 验证记录），先在 阿里云 RAM 获取 AccessKey：

# 设置阿里云 DNS API 密钥（用于自动验证域名）
export Ali_Key="LTAI5t***************"
export Ali_Secret="KDXj******************************"

# 签发证书
~/.acme.sh/acme.sh --issue --dns dns_ali -d cdn.yianso.cn

⚠️ 安全建议：在 RAM 访问控制创建子用户，仅授予 AliyunDNSFullAccess 权限，不要使用主账号密钥。

看到 Cert success. 和 Your cert is in: ... 即签发成功。

五、配置自动部署到七牛 CDN

设置七牛 API 密钥

在 七牛密钥管理 获取 AccessKey 和 SecretKey：

export QINIU_AK="tNCT7v*********************************"
export QINIU_SK="8Vis*********************************"

部署证书到七牛

~/.acme.sh/acme.sh --deploy -d cdn.yianso.cn --deploy-hook qiniu

看到 Domain cdn.yianso.cn certificate has been deployed successfully 即部署成功。

💡 提示：如果提示 400302 错误，需先在七牛 CDN 域名管理手动开启 HTTPS（选择已有证书），部署后再执行一次即可。

关键一步：设置续期后自动部署

默认续期只更新本地证书文件，不会自动部署到七牛。需要单独设置 renew-hook：

~/.acme.sh/acme.sh --set-renew-hook \
  "~/.acme.sh/acme.sh --deploy -d cdn.yianso.cn --deploy-hook qiniu" \
  -d cdn.yianso.cn

验证配置：

~/.acme.sh/acme.sh --info -d cdn.yianso.cn | grep renew_hook

输出中包含 renew_hook 指向 deploy 命令即配置正确。

验证自动续期

crontab -l | grep acme

会看到类似定时任务：

0 0 * * * "/home/myecs/.acme.sh"/acme.sh --cron --home "/home/myecs/.acme.sh" > /dev/null

acme.sh 每天自动检查，证书到期前自动续签 → 触发 renew-hook → 自动部署到七牛 CDN，全程无人值守。

踩坑记录

问题解决方案
