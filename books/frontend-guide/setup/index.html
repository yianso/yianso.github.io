1.1 什么是 Codex？

一句话定义

Codex 是 OpenAI 推出的 AI 编程智能体（Agent），它不是简单的代码补全工具，也不是一个聊天机器人——它是一个能够理解你的项目、自主完成任务、并交付结果的智能助手。

它和 ChatGPT 有什么不同？

这是新手最常问的问题。我们用一个例子来说明：

假设你想给登录页面加一个"记住密码"的功能。

用 ChatGPT：

  1. 你问："怎么实现记住密码功能？"
  2. ChatGPT 给你一段代码，解释原理
  3. 你自己打开编辑器，找到对应文件，粘贴代码，调试运行
  4. 整个过程，ChatGPT 只负责"说"，动手的是你

用 Codex：

  1. 你说："给登录页面加一个记住密码功能"
  2. Codex 自动读取你的项目代码，找到登录页面的相关文件
  3. 它分析现有代码结构，规划实现方案
  4. 它直接修改文件，添加功能代码
  5. 它运行测试，确认没有破坏其他功能
  6. 它把改动结果展示给你，等你确认
  7. 整个过程，Codex 既负责"想"，也负责"做"

核心区别：

维度ChatGPTCodex
角色定位顾问、参谋执行搭档、电子员工
工作方式你问它答你描述需求，它端到端完成
能力边界给建议、给代码片段读项目、改文件、跑测试、提交结果
你需要做的理解建议，自己实现描述需求，验收结果

一句话记住：

  • ChatGPT 帮你想清楚
  • Codex 帮你把事情做完

1.2 Codex 能帮你做什么？

编程场景

  • 修复 Bug：描述问题现象，Codex 自动定位并修复
  • 编写测试：告诉它要测什么，它自动写测试用例并运行
  • 重构代码：指定重构目标，它自动调整代码结构
  • 添加功能：描述需求，它自动实现并集成到项目中
  • 代码审查：让它检查代码质量，给出改进建议

非编程场景

Codex 不只是程序员的工具。它还能帮你处理日常办公任务：

  • 整理资料：把一堆 Word、PDF、PPT 归纳成摘要或汇报稿
  • 批量处理文件：修改 PPT 格式、插入二维码、调整排版
  • 制作表格：读取发票、行程单，自动生成 Excel 或报销表
  • 创建网页：生成可打开的本地网页，或直接部署到线上
  • 自动化任务：定时生成周报、检查网站更新、整理每日资讯

它不能做什么？

Codex 不是万能的，了解它的局限同样重要：

  • 不能替代专业判断：它可能会犯错，你需要验收结果
  • 不能处理模糊需求：需求越清晰，结果越好
  • 不能保证 100% 正确：复杂逻辑仍需要人工审核
  • 不能脱离上下文：它只能基于你提供的项目和文件工作
