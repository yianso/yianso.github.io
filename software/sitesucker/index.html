SiteSucker Pro

简介

SiteSucker 是一款 macOS 上的整站下载工具，可将整个网站下载到本地后离线查看。除 HTML 外，还可抓取站点结构下的文本、程序文件、图片、视频、音频等资源。

最新版本：Pro 6.2.1（2026-09-01）

主要能力

  • 整站镜像下载到本地硬盘
  • 保留站点整体架构，便于离线浏览
  • 资源类型覆盖页面、媒体与常见静态文件
  • 操作简单，适合备份或离线查阅网页内容
